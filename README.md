Generator kolorów (tzw. HEXCODEgen) jest aplikacją formularzową, napisaną za pomocą Visual Studio, której głównym zadaniem jest losowanie wartości dla trzech barw podstawowych: czerwonej, zielonej oraz niebieskiej. Na tej podstawie obliczane są wartości dla kodu CMYK, a więc dla barw: cyjanowej, magenta, żółtej oraz czarnej. HEXCODEgen posiada funkcję zresetowania wartości, a także zapisu do pliku .txt wylosowanego koloru, razem z aktualną datą i godziną. Program sam tworzy folder w Dokumentach na komputerze użytkownika (o ile takowy jeszcze nie istnieje) oraz plik, do którego ma być przesłana wartość.
